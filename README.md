# Zapper 📺

A web-based TV player with a virtual remote control and a customizable channel list.

Zapper lets you organize your favorite live TV streams and watch them through a simple, responsive interface.

## Features

- 📺 Web-based TV player
- 🎮 Virtual remote control
- 📋 Customizable channel list
- 🔢 Channel selection using remote control buttons
- 📱 Responsive design for desktop and mobile devices
- 🌐 Supports compatible live stream URLs

# Zapper — Türkçe

Zapper, sanal kumandası ve özelleştirilebilir kanal listesi bulunan, tarayıcı üzerinden çalışan bir TV oynatıcıdır.

Favori canlı yayınlarınızı düzenlemenizi ve uyumlu yayın bağlantılarını sade bir arayüz üzerinden izlemenizi sağlar.

## Özellikler

- 📺 Tarayıcı tabanlı TV oynatıcı
- 🎮 Sanal kumanda
- 📋 Özelleştirilebilir kanal listesi
- 🔢 Kumanda üzerinden kanal seçimi
- 📱 Bilgisayar ve mobil cihazlarla uyumlu tasarım
- 🌐 Uyumlu canlı yayın bağlantılarını destekler
